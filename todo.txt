# Manual Steps to Migrate Portfolio and Domains

Hello Anshumaan! Since changing domains on Vercel and creating a new repository on GitHub requires your personal login credentials, you will need to perform these steps manually.

Here is your to-do list:

### Step 1: Push the new portfolio to GitHub
1. Go to your GitHub account (https://github.com/).
2. Create a new repository (e.g., named "new-portfolio" or whatever you prefer).
3. Do NOT check "Initialize this repository with a README" (leave it empty).
4. Once created, copy the remote repository URL (e.g., https://github.com/anshumaanvats/new-portfolio.git).
5. Open your terminal in VS Code (in the `my-new-portfolio` folder) and run the following commands:
   ```bash
   git branch -M main
   git remote add origin <PASTE_YOUR_GITHUB_URL_HERE>
   git push -u origin main
   ```
   *(Note: I have already added the `Record` folder to `.gitignore`, so it will be kept hidden and won't be uploaded to GitHub.)*

### Step 2: Change the old portfolio's domain on Vercel
1. Go to your Vercel Dashboard (https://vercel.com/dashboard).
2. Open your old portfolio project (`AnshumaanVatsPortfolio`).
3. Go to the **Settings** tab, then click on **Domains** in the left sidebar.
4. You will see your current domain `anshumaanvats.vercel.app`.
5. Click the "Edit" button next to it (or "Add" a new one) and change it to `anshumaanvats17.vercel.app`.
6. Save the changes. (Your old portfolio is now moved to the new link).

### Step 3: Deploy the new portfolio to Vercel with the old domain
1. Go back to your Vercel Dashboard and click **Add New...** -> **Project**.
2. Import the new repository you just created in Step 1.
3. Click **Deploy** and wait for the build to finish.
4. Once deployed, go to the **Settings** tab of this new project.
5. Click on **Domains** in the left sidebar.
6. Enter `anshumaanvats.vercel.app` and click **Add**.
7. Vercel might warn you that the domain was used in another project (which you already changed in Step 2). Follow any prompts to assign it to this new project.

That's it! Your new portfolio will be live at `anshumaanvats.vercel.app` and your old one at `anshumaanvats17.vercel.app`.
