# Anshumaan Vats - Software Engineer Portfolio

Welcome to the source code for my personal portfolio website!

## 🚀 Live Demo
[anshumaanvats.vercel.app](https://anshumaanvats.vercel.app/)

## 🛠️ Built With
- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS** (for styling)
- **Framer Motion** (for smooth animations and transitions)
- **Lucide React** & **React Icons** (for iconography)

## 🌟 Key Features
- **Cinematic Parallax Scrolling**: A highly immersive front page.
- **Dynamic Backgrounds**: Change the ambient background video anytime via the navbar.
- **Interactive "Flipping" Business Card**: A fun UI element in the Contact section to reveal contact details.
- **Project Showcases**: Distinct sections highlighting software projects, hardware systems, achievements, and patents.

## 💻 Running Locally

To get a local copy up and running, follow these simple steps:

1. **Clone the repo**
   ```sh
   git clone https://github.com/anshumaanvats/new-portfolio.git
   ```
2. **Install NPM packages**
   ```sh
   npm install
   ```
3. **Run the development server**
   ```sh
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
